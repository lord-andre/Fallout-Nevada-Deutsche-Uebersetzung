# Fallout-Nevada-Deutsche-Uebersetzung
Fallout Nevada in Deutsch

Um Fallout Nevada auf Deutsch spielen zu können befolge folgende Schritte:
1) Lade dir die englische Extendet Fixed mod [hier](https://www.nma-fallout.com/threads/fallout-nevada-extended.207311/) runter.
2) Lade diese Repo über den grünen Knopf 'CODE' herunter. (Download Zip)
3) Erstelle im Nevada Ordner einen Ordner namens "patch002.dat"
   Ja wirklich, einen Ordner mit Punkt und Erweiterung dahinter :-)
4) Entpacke die Zip in den patch Ordner.

Fertig, sollte alles, bis auf die Stimmen deutsch sein.
