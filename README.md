# Fallout-Nevada-Deutsche-Uebersetzung
## Fallout Nevada in Deutsch

Diese deutsche Übersetzung wurde mithilfe von ChatGPT erstellt. 

Sie wird noch geprüft und bei Bedarf verbessert. 

Rückmeldungen und Korrekturvorschläge sind willkommen. 

---

**Installation:**

Um Fallout Nevada auf Deutsch spielen zu können befolge folgende Schritte:
1) Installiere **Fallout 2**, zum Beispiel über Steam.
2) Lade **[Fallout Nevada Extended](https://www.nma-fallout.com/threads/fallout-nevada-extended.207311/)** herunter und installiere die Mod
4) Lade dieses Repository über den grünen Code-Button als ZIP-Datei herunter.
6) Erstelle im **Nevada**-Ordner einen Ordner namens "patch002.dat"
   Ja wirklich, einen Ordner mit Punkt und Erweiterung dahinter :-)
7) Entpacke die heruntergeladene Zip in den patch Ordner.
8) Starte NevadaHD.exe

Fertig, sollte alles, bis auf die Stimmen und Bilder, deutsch sein.

Die Kinder, die in der deutschen Fallout-2-Version fehlen, sind in diesem Repository bereits enthalten. Ein zusätzlicher Kinder-Patch ist nicht erforderlich.
