# Fallout-Nevada-Deutsche-Uebersetzung
Fallout Nevada in Deutsch

Lade dir die Englishe Extendet Fixed mod [hier](https://www.nma-fallout.com/threads/fallout-nevada-extended.207311/) runter.

Lade diese Repo über den grünen CODE Knopf herunter. (Download Zip)

Erstelle im Nevada Ordner einen Ordner Namens: "patch002.dat"
Ja wirklich, einen Ordner mit Punkt und Erweiterung dahinter :-)

Entpacke die Zip in den patch Ordner.

Fertig, sollte alles, bis auf die Stimmen Deutsch sein.
